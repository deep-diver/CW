# Media Campaign Launch Desk

Media Campaign Launch Desk is a campaign operations benchmark target. It is
intentionally distinct from travel, grocery, home repair, and clinic command
surfaces: the UI centers on creative assets, channel calendars, rights
clearance, budget pacing, legal approvals, and launch ledgers.

| Tier | Directory | Focus |
| --- | --- | --- |
| A | `tier_a/` | Asset selection, schedule placement, budget commit, rights check, legal approval, and launch ledger |
| B | `tier_b/` | Broadcast release switcher, source wall, rundown timing, caption/localization gates, partner trafficking, transmission ledger, and audit persistence |
| C | `tier_c/` | Omnichannel media investment control room with audience opportunity maps, channel-mix allocation, reach/frequency forecast, inventory deal intake, brand-safety validation, holdout experiments, pacing guardrails, activation ledger, and audit persistence |
| D | `tier_d/` | Global premiere embargo command center with cinematic asset locks, market blackout matrices, partner traffic manifests, measurement beacons, sentiment and escrow gates, multi-role sign-offs, post-seal reopening, and executive launch sealing |

Each tier is a complete DetoxBench DSL target with its own public contract,
scenario suite, and reference implementation. Tier B currently includes public
scenarios only; Tier C includes 24 public and 20 private scenarios; Tier D
includes 20 public and 28 private scenarios.
